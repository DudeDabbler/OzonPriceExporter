OZON CUSTOMER PRICE EXPORTER 0.1.2 — PORTABLE WINDOWS x64
================================================================
Publisher: DudeDabbler
Repository: github.com/DudeDabbler/OzonPriceExporter

ЗАПУСК
1. Полностью распакуйте ZIP в обычную папку.
2. Запустите OzonPriceExporter.exe.
3. В интерфейсе создайте/выберите профиль магазина, откройте Ozon и войдите.
4. Нажмите «Проверить вход», затем «Собрать цены».
5. После завершения скачайте Excel.

УСТАНОВКА НЕ НУЖНА
- Python, pip и виртуальное окружение пользователю не требуются.
- Права администратора не требуются.
- Нельзя запускать EXE прямо внутри ZIP: сначала распакуйте весь каталог.
- На компьютере должен быть установлен Google Chrome или Microsoft Edge.

ДАННЫЕ И АВТОРИЗАЦИЯ
По умолчанию профили браузера и Excel хранятся отдельно от программы:
%LOCALAPPDATA%\IFOAM\OzonPriceExporter

Исторический путь сохранён, чтобы существующие авторизованные профили продолжили
работать после перехода в отдельный репозиторий. Логин и пароль приложение не
читает: они вводятся только на Ozon.

Для переопределения каталога можно задать:
DUDEDABBLER_OZON_PRICE_EXPORTER_HOME=<путь>

Совместимый старый alias также поддерживается:
IFOAM_OZON_PRICE_EXPORTER_HOME=<путь>

Не передавайте папку профиля другим людям: в ней находятся cookies авторизации.

БЕЗОПАСНОСТЬ
- Приложение работает только на чтение и не изменяет цены/товары/акции.
- Локальный HTML-сервер и CDP слушают только 127.0.0.1.
- Используется установленный обычный Chrome/Edge без --no-sandbox.
- Сборка не подписана цифровой подписью; Windows может показать SmartScreen.

ДИАГНОСТИКА
Если программа не открылась, проверьте:
%LOCALAPPDATA%\IFOAM\OzonPriceExporter\startup_error.log

В BUILD_MANIFEST.json указаны версия, repository, commit и параметры сборки.
